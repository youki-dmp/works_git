# Local Markdown Viewer Extension

ローカルの `.md` ファイルをブラウザで開いた際に、GitHub風の美しいスタイルで表示し、目次機能やメディア再生機能を追加するChrome拡張機能です。

## 特徴

- **GitHub風プレミアムスタイル**: システム設定に連動するライト/ダークモード対応。
- **レスポンシブ目次 (ToC)**: 画面サイズに応じてフローティング表示やトグルメニューに自動切り替え。
- **メディア対応**: YouTubeリンクの自動埋め込み、画像、GIFアニメの再生。
- **クイックジャンプ**: 目次をクリックするとスムーズに見出しへスクロール。

## インストール方法（重要）

1.  このディレクトリをローカルに保存します。
2.  Chromeブラウザで `chrome://extensions/` を開きます。
3.  右上の **「デベロッパー モード」** をONにします。
4.  **「パッケージ化されていない拡張機能を読み込む」** をクリックし、このフォルダ（`apps/local-markdown-viewer`）を選択します。
5.  インストール後、本拡張機能の **「詳細」** ボタンをクリックします。
6.  設定画面を下へスクロールし、**「ファイルの URL へのアクセスを許可する」をONにします**。
    > [!IMPORTANT]
    > この設定を忘れると、ローカルの `.md` ファイルで拡張機能が動作しません。

## 使い方

1.  任意の `.md` ファイルをChromeにドラッグ＆ドロップします。
2.  自動的にGitHub風のスタイルに変換され、右側に目次が表示されます。
3.  画面が狭い（タブレットやスマホサイズ）場合は、右下の **「目次」ボタン** からメニューを開けます。

## 開発スタック

- JavaScript (Content Script)
- Vanilla CSS (GitHub Markdown Style)
- [Marked.js](https://marked.js.org/) (Markdown Parser)
