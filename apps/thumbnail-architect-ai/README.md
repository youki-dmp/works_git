# サムネイル職人 AI Studio (Thumbnail Architect AI)

Google Gemini 3.5 Flash & Gemini 3 Pro AI エンジンを活用したプロ仕様の YouTube サムネイル自動生成・設計アプリケーション。

---

## 📌 プロジェクトの目的 (Project Purpose)
YouTubeでのクリック率 (CTR) を最大化するため、単なる画像生成にとどまらず、**競合差別化の戦略プラン策定 -> 3パターンのプロトタイプ生成 -> 人物画像非加工の精密レイヤー重ね合わせ -> プロ品質仕上げ** までを自動化・シームレスに行うクリエイティブスタジオです。

---

## 🎨 主な特徴と機能 (Key Features)

### 1. クリーン＆プレミアムな最新ライトテーマ UI
- 明るく清潔感のあるピュアホワイト＆インディゴ基調のデザイン。
- 日本語フォント (`Noto Sans JP`) とモダン英文フォント (`Plus Jakarta Sans`) による美しいタイポグラフィ。

### 2. 人物画像の直接非加工＆レイヤー合成 (`preserveRawSubjectLayer`)
- アップロードされた被写体（人物・キャラ立ち絵）の顔や服装をAIで再描画・歪めたりせず、**そのままのレイヤーとして背景・テキスト・エフェクトと重ね合わせ**。
- 生成結果から **透過レイヤー別 Zip 書き出し (背景/人物/テロップ/エフェクト)** に対応。

### 3. 最新 AI モデルの二段構成
- **Speed モード**: `gemini-3.5-flash` による超高速生成。
- **Pro モード**: `gemini-3-pro-image-preview` による最高画質・正確な構図・和漢文字グラフィック生成。

### 4. YouTube 実用検証機能
- **セーフゾーン 1:23 オーバレイ**: サムネイル右下の再生時間表示バッジとの文字被りを1クリックで確認。
- **YouTube モバイル実機シミュレーター**: スマホフィードでの見え方をリアルタイムプレビュー。

## 📖 マニュアル・使用方法 (Usage Manual)

### 1. デザイン構成入力
1. **画像アセット**: 被写体人物画像、ロゴ画像、背景用スクショ、参考サムネイル（最大3枚）をアップロード。
2. **モデルモード選択**: 右上のトグルで `Speed (3.5 Flash)` または `Pro (3 Pro Image)` を選択。
3. **コピー＆ターゲット設定**: メインコピー、サブコピー、ターゲット感情（衝撃、雑談、歌枠など）を入力し、「AI戦略プランを策定する」をクリック。

### 2. ラフ案選択 & AI添削
1. 提案された 3 つのプロトタイプから好みの案を選択。
2. 必要に応じて「プロ視点で添削（AI Critique）」を実行し、改善アドバイスを適用。

### 3. 最終レンダリング & 保存
1. ピンポイント修正指示を入力して最終ポリッシュを実行。
2. 「サムネイル画像を保存」または「透過レイヤー別 Zip 書き出し」でアセットをダウンロード。

## 🚀 セットアップと実行 (Setup & Run)

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build
```

環境変数設定: `.env.local` に API キーを設定してください。
```env
API_KEY=YOUR_GEMINI_API_KEY
```
