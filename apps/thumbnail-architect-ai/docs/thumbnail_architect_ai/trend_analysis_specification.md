# トレンド分析モード (Trend Analysis Mode) 仕様書

## 1. 目的
現在の YouTube トレンドをリアルタイム（または定期取得データ）で分析し、サムネイル作成の戦略に反映させることで。競合との差別化（逆張り）や、クリック率の高いパターンの模倣を自動化します。

## 2. 収集データ
- **YouTube Data API** を活用して以下の情報を取得します：
  - 指定キーワード（`competitorKeyword`）での検索上位 20 動画。
  - 類似チャンネルの最新アップロード動画。
- **取得項目**:
  - サムネイル画像（URL）
  - 動画タイトル
  - 再生回数・投稿日時（人気度・鮮度の確認）

## 3. 分析ロジック (AIによる分析)
取得したデータを Gemini Pro (Vision) に入力し、以下の傾向を抽出します：
- **配色傾向**: どの色が支配的か（例：赤と黄色が80%を占めるなど）。
- **構図パターン**: 顔のアップ、文字のみ、比較画像など。
- **テキストスタイル**: 使われているフォントの雰囲気、強調キーワード。

## 4. 戦略プランへの反映
分析結果に基づき、`generateDesignPlan` 時に以下の指示をプロンプトに動的に追加します：
- **差別化戦略**: 「競合は青色を多用しているため、補色のオレンジをメインにしてください」等。
- **フックの強化**: 「最近の伸びている動画は『絶望感』を強調しているため、表情をより大げさにしてください」等。

## 5. UI/UX
- 設定フォームの「Research Mode」トグルが ON の場合に発動。
- 分析完了後、戦略レポートに「トレンド分析結果」セクションを追加。
