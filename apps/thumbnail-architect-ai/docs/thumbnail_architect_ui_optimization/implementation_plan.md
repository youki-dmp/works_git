# サムネイル職人 AI UI・仕組み・高速化・出力ルール改善計画 (改訂版)

## 概要
ユーザーフィードバックに基づき、**典型的なAI風ダークモードから脱却したクリーンで洗練された高級ライトテーマUI**を構築します。
また、**Gemini 3.6 (gemini-3.6-flash / gemini-3.6-pro 等) などの最新AIモデルを全面採用**し、処理の高速化および日本語タイポグラフィ・人物同一性ルールの厳格遵守を実現します。

## 主な変更点
1. **明るく洗練された「クリーン＆プレミアム ライトテーマ」UI**
2. **Gemini 3.6 シリーズモデルの採用とスピード/品質モード切替**
3. **並行処理・進行フィードバックの高速化**
4. **出力ルールの厳格化（日本語文字・人物同一性・セーフゾーン）**
5. **YouTubeフィード実演ビュー & セーフゾーンガイドライン overlay 機能**

- `config.ts`
