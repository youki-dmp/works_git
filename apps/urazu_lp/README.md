# Urazu LP

個人VTuberのための戦略的パートナー「Urazu（ウラズ）」のランディングページです。

## 公開URL
- [https://dsm.static.jp/urazu/](https://dsm.static.jp/urazu/)

## 目的
ターゲット層の課題（事務作業への圧迫）に寄り添い、AIツールやディレクター伴走サポートなどの解決策を提示し、無料モニターへの登録を促すことを目的としています。デザインはVTuber文化に親和性の高い「Cyber-Pop Editorial」コンセプトを採用しています。

## マニュアル（使い方）
- `index.html` をブラウザで開くことでローカル環境で表示を確認できます。
- デザインやテキストを変更する場合は、`index.html` および `css/style.css` を編集してください。
- フォームのリンク先は `<a href="https://forms.gle/i6UvgR2FYdrqvvG99">` に設定されています。変更が必要な場合は一括置換してください。
