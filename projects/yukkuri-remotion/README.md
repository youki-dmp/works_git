# Yukkuri Commentary Video Generation (Remotion x VOICEVOX)

## 概要
Remotion（Reactビデオ制作フレームワーク）とVOICEVOXを組み合わせ、「ゆっくり解説」スタイルの動画をテキストから完全自動生成するプロジェクトです。

## 技術スタック
- **Remotion**: 動画レンダリング、アニメーション、シーケンス管理。
- **VOICEVOX**: 音声合成（ずんだもん、四国めたん等）。
- **Antigravity (LLM)**: 台本作成、登場人物の役割分担、タイミング制御。
