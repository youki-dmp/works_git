# Yukkuri Commentary Video Generation (Remotion x VOICEVOX)

## 概要
RemotionとVOICEVOXを組み合わせた「ゆっくり解説」自動生成プロジェクト。
現在はYouTubeの「量産型・再利用コンテンツ」ポリシーへの厳格な対応戦略を策定し、実装フェーズに移行しています。

## 最新トピック (2026-02-05)
- **収益化ポリシー対策**: 「カオス・インジェクション」と「独自の見解挿入」によるハイブリッド運用。
- **動的背景の導入**: Google Labsの「Flow」および最新モデル「Veo 3」を活用し、固定画像ではない、ループ動画や動的な背景生成をパイプラインに組み込みます。

## 技術スタック
- **Remotion**: 動画レンダリング、アニメーションロジック。
- **VOICEVOX**: 音声合成。
- **Google Veo 3 / Flow**: 高品質な動的背景・シーン生成。
- **Antigravity (LLM)**: 台本作成、独自性の付与、全体指揮。
